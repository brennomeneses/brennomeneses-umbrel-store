# 9Router Umbrel Community App Store

A custom Umbrel Community App Store that packages the [9Router](https://github.com/decolua/9router) service as an installable Umbrel app.

## Add this app store to umbrelOS

In umbrelOS, go to the App Store, click the user menu and select "Add custom app store", then point it at this repository's GitHub URL once it is published.

## Apps

- `nine-router-9router` — 9Router unified AI API router/aggregator
